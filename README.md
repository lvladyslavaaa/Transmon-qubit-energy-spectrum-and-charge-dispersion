Transmon Qubit Energy Spectrum & Charge Dispersion

This repository contains a Python script for numerical simulation and visualization of a Transmon qubit. The project calculates the Hamiltonian in the phase basis, solves for the low-lying energy levels and wavefunctions, and analyzes the charge dispersion splitting vs. offset charge. 

Features:
Numerical diagonalization of the transmon Hamiltonian.
Calculation of probability wavefunctions in the phase basis.
Simulation of qubit transition frequency as a function of offset charge across various EJ/EC ratios.
Automated plotting and saving of publication-ready figures.

Requirements:
To run this script, you need Python installed along with the following libraries:
`numpy`
`matplotlib`
